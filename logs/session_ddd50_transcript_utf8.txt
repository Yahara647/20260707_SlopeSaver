**`git fetch`** は、リモートリポジトリ（GitHub）の最新情報をローカルに取得するコマンドです。

## 何をするのか

```
GitHub（リモート）
    ↓ 情報を取得
ローカルリポジトリ
```

## 重要なポイント

| 項目 | 説明 |
|------|------|
| **取得内容** | ブランチ、コミット、タグなど、リモートの更新情報 |
| **ワーキングディレクトリへの影響** | なし（ファイルは変わらない） |
| **追跡ブランチの更新** | リモート追跡ブランチが更新される |

## 実例

```bash
git fetch origin
```
この場合、GitHubの `origin` から最新情報をダウンロード

## `git fetch` と `git pull` の違い

| コマンド | 内容 |
|---------|------|
| `git fetch` | リモートの情報を取得するだけ |
| `git pull` | リモートの情報を取得 + ローカルブランチにマージ |

## なぜ必要か

GitHub UIで新しいブランチを作成した場合、ローカルにはまだその情報がないので、`git fetch` で同期してから `git checkout` できるようにしているわけです。

理解した処理方針を述べます。

**前提**: `led_frame_points` の y 座標を昇順に並べると `y[0] < y[1] < ... < y[n-1]` となる。

**上端の除去**:
- ギャップ = `y[1] - y[0]`（上から2番目と1番目の間隔）
- 有効上限 = `y[0] - ギャップ`
- スリット光点の `y < 有効上限` を除去

**下端の除去**:
- ギャップ = `y[n-1] - y[n-2]`（下から1番目と2番目の間隔）
- 有効下限 = `y[n-1] + ギャップ`
- スリット光点の `y > 有効下限` を除去

**具体例**: LED y座標が `[100, 120, 140, 160, 180]` の場合：
- 上端: 100 - (120-100) = **80** → y < 80 のスリット光点を除去
- 下端: 180 + (180-160) = **200** → y > 200 のスリット光点を除去

つまり「LEDの配置間隔1つ分だけ外側まで許容する」というロジックです。

## `z = a * y + b` の最小二乗法

### 入力データ

| 検出LED | 画像 y 座標 | 実空間 z 座標（config） |
|---|---|---|
| LED 3 | y = 620 px | z = 130 mm |
| LED 4 | y = 560 px | z = 140 mm |
| LED 5 | y = 500 px | z = 150 mm |
| LED 6 | y = 440 px | z = 160 mm |
| LED 7 | y = 380 px | z = 170 mm |

※ y が大きい（画像下） = z が小さい（実空間）という逆の関係

---

### 計算式

$$\mathbf{A} = \begin{bmatrix} y_1 & 1 \\ y_2 & 1 \\ \vdots \\ y_N & 1 \end{bmatrix}, \quad \mathbf{z} = \begin{bmatrix} z_1 \\ z_2 \\ \vdots \\ z_N \end{bmatrix}$$

最小二乗解：

$$\begin{bmatrix} a \\ b \end{bmatrix} = (\mathbf{A}^T \mathbf{A})^{-1} \mathbf{A}^T \mathbf{z}$$

上の例では `a ≈ -0.167`（負の傾き）、`b ≈ 253` 程度になります。

---

### コード上の実装

```python
A = np.vstack([y_sorted, np.ones(len(y_sorted))]).T
# A shape = (N, 2):  [[y1, 1], [y2, 1], ...]

coeffs, _, _, _ = np.linalg.lstsq(A, z_sorted, rcond=None)
# coeffs[0] = a（傾き）
# coeffs[1] = b（切片）
```

ただし、この線形係数は**参考値として保存するだけ**で、実際の z 取得には使われていません。実際は `np.interp()` による補間テーブルを使っています：

```python
z_interp = np.interp(y_range, y_sorted, z_sorted)
# → 各 y 値に対して z を線形補間
```

## `np.interp()` による補間テーブル

### 処理の流れ

```python
# ① 検出LED点のy-z対応（例: 5点）
y_sorted = [380, 440, 500, 560, 620]  # 画像y座標（昇順）
z_sorted = [170, 160, 150, 140, 130]  # 実空間z座標（対応）

# → [380.0, 380.24, 380.48, ..., 620.0]

z_interp = np.interp(y_range, y_sorted, z_sorted)
# → [170.0, 169.95, 169.90, ..., 130.0]
```

`np.interp(x, xp, fp)` は「既知の点 `(xp, fp)` の間を**折れ線**で繋いで、任意の `x` での値を返す」関数です。

```

160   ●
150     ●     ← 補間テーブルはこの線上の1000点
140       ●
130         ●
    380 440 500 560 620  →  y
```
